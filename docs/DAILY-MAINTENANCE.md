# 每日身体维护：首版实现与验收

状态：0.9.0-preview.1 已构建为 PR 试用包，尚未合并或发布到 Releases。基于 main `8cafb4738a0cb332906cb39e34f29cc636df1b80`。

## 用户流程

- 首页「每日身体维护」进入今日进度，选择短维护或完成今日剩余。
- 默认目标为 8 分钟实际跟练，可设 5–10 分钟。每个动作另有 5 秒准备；所有启动按钮与全屏总进度包含准备时间。默认短维护为 2:10，集中完成 8 分钟跟练为 8:40。
- 自动安排需在维护偏好开启；沿用原有身体休息周期、静默与返回缓冲，不新增独立定时器。当天目标完成后改为自由休息；普通休息与 7 分钟活动也尊重部位和动作禁用，不重新安排指定动作。原有 7 分钟活动独立保留。
- 13 个基础动作，覆盖胸椎、肩胛、髋部、腿后侧、踝与小腿，以及默认关闭的颈部动作。可排除部位、站姿及指定动作。
- 跟练页提供原生矢量示意、准备与左右侧提示、可选的 Windows 中文 SAPI 语音；没有中文语音时完整保留文字引导。动画不参与计时。
- 完成后先释放强制全屏，再询问是否跟练；勾选实际做过的动作才计入今日。倒计时结束、跳过、退出、选择没有跟练都不会自动记为完整跟练。
- 「不适，立即停止」直接关闭维护及副屏窗口，并暂停推荐当前动作。恢复需在维护偏好中取消该动作的暂停标记并保存。

## 计时与记录

Core 不读取系统时间；Advance 接受单调时钟差值和本地时间样本。大于 10 秒的未知间隙不补计，Windows 控制器在锁屏、睡眠、最小化和长间隙后要求手动继续。

只记录练习阶段的时间，准备、暂停、被替换动作的旧进度不算跟练。跨午夜的练习按各段实际本地日期分配，即使用户稍后才确认，也不会全部归到确认日。短维护和集中维护读取同一份日覆盖量；旧日未完成目标不追补。

确认只能提交一次。部分跟练按所选动作的实际观察时长记录，不伪造百分比或完整次数。仅完整跟练且确认至少两分钟练习，才重置连续工作暴露；不同时增加原有身体活动或 7 分钟活动次数。CSV 增加 `maintenance_confirmed_minutes`。

数据格式升至 schema 2，兼容读取并迁移 schema 1。旧版程序会以只读方式保护新格式。损坏的部位枚举、空字典、负值和无效数值不覆盖原文件。保存失败保留本次内存记录并显示原有错误提示，后续重试不重复累计；进程在成功保存前退出仍可能丢失记录。

## 健康内容边界

这是一般性活动提示，不是康复处方或关节活动度测量。每日 5–10 分钟是习惯目标，不是统一医学剂量；不替代有氧与力量训练。不要求极限幅度，不把疼痛当作进步。已有疾病、近期伤病、手术或医生限制时应避开不适合的动作。

参考依据：

- NHS 坐姿练习：https://www.nhs.uk/live-well/exercise/sitting-exercises/
- NHS 柔韧性练习：https://www.nhs.uk/live-well/exercise/flexibility-exercises/
- WHO 身体活动：https://www.who.int/news-room/fact-sheets/detail/physical-activity
- NHS 颈部问题：https://www.nhsinform.scot/illnesses-and-conditions/muscle-bone-and-joints/neck-and-back-problems-and-conditions/neck-problems/

这些资料支撑一般内容选择，并不构成本项目动作、动画或组合剂量经过临床验证。原生示意仍需逐项检查与专业内容复核，不能标注为已通过康复专业审核。首批未纳入深蹲停留及髋屈肌静态拉伸；目前以低门槛坐站及温和髋部活动起步。
