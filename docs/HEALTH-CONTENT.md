# 健康内容与产品边界

本版本提供一般性活动提示，不是医疗器械、诊断系统或疾病康复处方。不根据“颈椎病”“膝痛”等标签自动开具动作组合。

## 内容原则

1. 优先改变姿势、离开座位和行走。不能站立时允许调整坐姿，不把站立设为完成门槛。
2. 默认轻柔版本，排除跳跃、地面动作、压头、绕颈、强行牵伸和高强度循环训练。
3. 普通版本增加坐站、墙壁俯卧撑、扶稳提踵。它们不是对所有人无风险的动作，用户可以跳过或停止。
4. 7 分钟为便于工作日安排的产品时长，不承诺等价于经典 HIIT 或满足全天运动需求。
5. 不声称“预防椎间盘突出”“治疗腰痛”“抵消久坐伤害”，不展示缺乏验证的工位健康分数。
6. 提示不适即停止；有既往疾病、伤病、术后限制时遵循医生或康复师建议。

## 参考依据

- [OSHA：电脑工作站姿势](https://www.osha.gov/etools/computer-workstations/positions)：工位中经常变换位置与姿势，而非长时间固定一个“完美坐姿”。
- [Mayo Clinic：眼疲劳的诊断与处理](https://www.mayoclinic.org/diseases-conditions/eyestrain/diagnosis-treatment/drc-20372403)：20-20-20 是可使用的远眺休息提示，不是本软件有效性的临床证据。
- [Mayo Clinic：办公室人体工学](https://www.mayoclinic.org/healthy-lifestyle/adult-health/in-depth/office-ergonomics/art-20046169)：工位调整以及站起、活动、改变姿势的一般建议。

20 / 60 分钟间隔及具体 3 / 7 分钟动作编排是可调整的产品设计，不宣称这些组织认可了此完整方案。公开发布前应安排专业内容审阅和不同身体条件用户的试用反馈。
