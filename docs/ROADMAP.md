# 后续优先级

## 下一批：让日常使用可信

1. Windows 实机完成验收清单，修复混合 DPI、锁屏和全屏边界。
2. 一周自用反馈：误打断次数、自然休息误判、退出原因、提醒接受率；先人工记录，不引入遥测。
3. 专业审阅活动文案，补充明确、可访问的动作教学资源。
4. 签名与安装 / 卸载流程，确认发布渠道，再做自动更新。

## 有依据再增加

- 7 分钟活动的预约时间（每日安静时段已实现）。
- 多显示器同步显示，确保仍可一键退出。
- 用户显式选择通话状态，或接入能证明通话状态的可靠平台事件；不能仅凭会议进程存在就判定在开会。
- 周趋势（本地 CSV 导出已实现）；事件级存储需求明确后迁移 SQLite。
- 工位自查，提供具体调整建议，避免伪精确健康评分。

## 保持克制

不做不可退出的强制锁机、不以症状自动给出康复处方、不做云账号、社区、排行榜、摄像头姿势识别或卡路里估算。
