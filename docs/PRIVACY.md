# 隐私说明

工作防沉迷 0.1.0 不要求账户，不包含广告、分析 SDK、崩溃上报或应用遥测，不主动向任何服务器发送数据。

本地保存：休息间隔、显示设置、开机启动偏好、是否启用轻柔动作，以及最近 90 天的电脑活动估计、最长连续时间、三类活动流程完成次数。

临时读取：当前用户会话的最近输入时间、锁屏与电源事件、前台窗口 PID 和矩形、多显示器位置与 DPI。只用于计时和提醒，不保存窗口标题、应用使用历史或输入内容。手动会议模式只存在本次运行内存中。

数据位于 `%LOCALAPPDATA%\WorkGuard`，以未加密 JSON 保存，受当前 Windows 用户文件权限保护。能访问该用户文件的人可以阅读它；不要把此目录放入公开共享目录。备份文件可能保留上一次保存时的汇总记录。

用户主动开启开机启动后，程序仅修改当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WorkGuard` 项，不要求管理员权限。

清除数据：先在托盘退出应用，再删除数据目录。移除应用前先关闭设置中的开机启动，然后退出并删除程序文件。卸载后本地数据不会由其他服务继续处理。

源码构建时，.NET SDK 与 GitHub Actions 自身可能具有独立的网络、日志和遥测行为，不属于本应用运行期的数据收集。
