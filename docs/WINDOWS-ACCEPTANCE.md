# Windows 11 人工验收

以下检查尚需真实 Windows 会话执行；CI 的自动启动检查只覆盖窗口加载和基础 API，不替代人工验收。

- [ ] 解压便携版运行，无需安装 .NET、无需管理员权限。
- [ ] 第一次打开设置，保存后托盘可见；重启后恢复设置且不重复首次引导。
- [ ] 第二次启动提示已有实例，不产生两个计时器。
- [ ] 概览关闭后托盘继续运行；托盘退出后所有窗口和进程终止。
- [ ] 手动开始眼睛休息，点击开始后 20 秒自动结束，有系统提示音。
- [ ] 身体活动逐步计时，暂停后不加时；跳过某步后结束不记为完整活动。
- [ ] 3 分钟完成仅记一次；7 分钟完成只增加办公室活动次数及身体总次数，不重复记两类。
- [ ] 刚完成眼睛休息时，身体连续计时仍保留。
- [ ] 推迟 / 关闭休息窗口后，至少 5 分钟内不再次提示。
- [ ] 会议模式无输入 6 分钟仍计时，不弹窗；关闭会议模式后恢复提醒。
- [ ] 全屏视频时静默计时；普通最大化窗口不应误判为全屏。
- [ ] 锁屏 30 秒不清零连续计时；锁屏 5 分钟清零但不增加完成次数。
- [ ] 休息过程中睡眠，唤醒后保持暂停，不跨越动作自动完成。
- [ ] 自然休息开启时空闲 5 分钟清零；关闭时持续累计用屏估计。
- [ ] 双屏含负坐标、100% / 150% / 200% 混合 DPI：覆盖鼠标所在屏幕，正文不裁切，退出按钮可访问。
- [ ] 拔掉显示器时关闭覆盖层，不留下不可访问窗口。
- [ ] 屏幕分辨率 1280×720、系统文字放大：设置和概览可滚动，无关键按钮被遮挡。
- [ ] 使用 Tab / Enter / Space / Esc 可以操作关键流程，焦点可见。
- [ ] 跨午夜活跃秒数分配到对应日期；最近 7 天表格正确显示无数据日期。
- [ ] 开机启动选项只影响当前用户，取消后对应注册表项删除。
- [ ] 退出备份数据后，损坏 state.json 再启动：提示只读、原文件保持不变。
- [ ] 移动应用目录后重新保存开机启动，登录时启动路径正确。
- [ ] 任务管理器观察资源占用；记录空闲 30 分钟 CPU、内存和提醒时峰值，再决定优化。

验收时记录：系统版本、CPU 架构、屏幕布局、缩放比例、版本号、失败步骤和实际结果。不要在缺少测量的情况下宣称低内存占用或多屏完全兼容。
