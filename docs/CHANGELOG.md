# 0.7.0 · 工作日节奏

- 新增工作日与跨午夜时段配置，默认关闭；静默保留连续暴露计时，手动休息随时可用。
- 每日 7 分钟活动预约，30 分钟有界等待、当日去重、重启和时钟回拨保护；仅轻提醒，不强制训练。
- 静默结束后保留 15 秒单调计时缓冲；长卡顿和睡眠不补算，新的静默重新开始缓冲。
- 首页、托盘与「我的安排」统一展示真实提醒状态；原生 24 小时时间轴展示今日工作与安静时段。
- 预约保存失败不弹出、不假报送达；设置变更保留预约去重记录。
- 60 项核心测试，Windows 原生检查增加预约等待、恢复缓冲、非强制开始、重启去重、设置校验与保存失败。

# 0.6.0 · 入门与休息反馈

- 三步入门：节奏、提醒力度、确认保存。支持返回修改和保存失败重试，关闭不落盘；未完成配置前静默计时。
- 概览增加快速配置入口，复用已有偏好，不覆盖未展示的高级选项。
- 休息页增加三环节动作路线，随当前环节更新；安静替代隐藏动作列表。
- 跳过后的结束页呈现实际进度；完整结束在概览显示短暂反馈，区分眼睛、身体和安静替代。
- 45 项核心测试；Windows 原生检查增加引导返回 / 重试 / 放弃、紧凑布局和反馈语义。

# 0.4.0 · 强制休息

- 用户可开启到点自动全屏的强制模式，眼睛与身体活动可区别设置。
- 统一计时的多屏遮罩；普通跳过 / 推迟禁用，紧急退出确认，结束自动返回。
- 四类场景配色和轮换引导；可选温和转头，安静休息替代不缩短时长、不记身体活动。
- 锁屏 / 睡眠暂停需恢复，显示器变更释放，Windows 系统退出仍然可用。
- 42 项核心测试；新增 Windows 强制界面与完成、退出、替代、暂停和控制器统计检查。
