# 更新记录

## 0.3.0

- 新增两幅离线插画，覆盖概览、设置、轻提醒、活动准备和完成状态。
- 增加 Windows 原生图标、彩色统计标记和两张独立活动入口卡片。
- 统一设置开关、输入框、按钮及标签页，保留键盘操作和文字标签。
- 活动按钮固定在底部；进行中收起插画，结束后恢复温和的视觉反馈。
- 图像限尺寸解码，Windows 检查验证嵌入图片与图标字形可用。
- 精简包包含插画，继续由 GitHub Actions 检查后自动发布。

## 0.2.0

- 重做今日概览、七日记录与分组设置，修复 WPF 派生窗口未应用字体和背景样式、表格列宽挤压。
- 新增不抢焦点的轻提醒；活动准备时不全屏，用户开始后才进入覆盖层。
- 活动加入下一步预告，切换与结束声音可选，支持暂停和随时退出。
- 每日安静时段支持跨午夜；提供日常与专注节奏预设。
- 修复只读数据仍假装保存成功的问题；备份验证和恢复会保留原文件。
- CSV 导出、跨午夜活跃时间分配、旧偏好数据兼容。
- 重复启动激活原窗口，跨会话文件锁避免并发写入，本地故障日志与会话结束保存。
- 35 项确定性行为测试，Windows CI 覆盖真实窗口、布局和休息交互，并保存 11 个界面状态截图。
- 自动发布只提供精简版，目标 Windows 10 22H2 / Windows 11 x64。

预发布状态保留：没有代码签名，尚需目标系统实机长时间、多显示器和辅助技术验收。自动检查通过不等于完成全部生产验收。
