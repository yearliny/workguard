# 0.4.0 · 强制休息

- 用户可开启到点自动全屏的强制模式，眼睛与身体活动可区别设置。
- 统一计时的多屏遮罩；普通跳过 / 推迟禁用，紧急退出确认，结束自动返回。
- 四类场景配色和轮换引导；可选温和转头，安静休息替代不缩短时长、不记身体活动。
- 锁屏 / 睡眠暂停需恢复，显示器变更释放，Windows 系统退出仍然可用。
- 42 项核心测试；新增 Windows 强制界面与完成、退出、替代、暂停和控制器统计检查。
